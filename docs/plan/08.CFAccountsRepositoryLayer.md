# Task 8 — CF-Accounts Repository Layer

## Context

The repository layer is the DB/external API layer for CF-Accounts. It implements ScyllaDB access for four domains: accounts, tenants, networks, and credentials. Each domain lives in its own subfolder with `api.go` (interface), `repository.go` (implementation), `models.go` (persistence models), and `errors.go` (typed errors).

Repository layer models must never be leaked into the service layer. All conversions happen via explicit transform methods.

Reference: `docs/cf-private-network.md` section 13.7 (DB layer file conventions) and `docs/rest-services-rules.md` (repository layer rules).

## Dependencies

Tasks 1, 2, 3, and 7 must be complete.

## Prompt

You are implementing the repository layer for **CF-Accounts** — the `internal/repository/` packages inside `services/cf-accounts/`.

### Architecture rules (mandatory):
- Each repository subfolder is independent — no cross-imports between repository subfolders
- `api.go` defines the interface and `New()` constructor returning the interface
- `repository.go` contains the concrete `CFAccounts<Name>Repository` struct (unexported concrete type, returned as interface)
- `models.go` defines persistence models — structs that map directly to CQL rows
- `errors.go` defines typed errors for this repository using `libs/cloudforge-core/pkg/errors`
- All errors returned by the interface methods are typed `CFError` values — never raw gocql errors
- Methods must respect the provided `context.Context`

### `internal/repository/accounts/`

**`api.go`:**
```go
type AccountsRepository interface {
    Insert(ctx context.Context, row AccountRow) error
    GetByID(ctx context.Context, id string) (AccountRow, error)
    GetByEmail(ctx context.Context, email string) (AccountRow, error)
    List(ctx context.Context, limit, offset int) ([]AccountRow, int, error)
    UpdateStatus(ctx context.Context, id string, status string) error
}

func New(session *scylladbclient.Session) AccountsRepository
```

**`models.go`:**
```go
type AccountRow struct {
    ID        gocql.UUID
    Email     string
    Status    string
    CreatedAt time.Time
    UpdatedAt time.Time
}
```

**`repository.go`:** Implement `CFAccountsAccountsRepository` using the ScyllaDB session.
- `Insert`: writes to both `accounts` and `accounts_by_email`
- `GetByID`: queries `accounts` by primary key
- `GetByEmail`: queries `accounts_by_email`
- `List`: queries `accounts` with `LIMIT` (implement offset by token-based pagination or simple offset for v1)
- `UpdateStatus`: `UPDATE accounts SET status=?, updated_at=? WHERE id=?` and updates `accounts_by_email`

**`errors.go`:**
```go
var (
    ErrAccountNotFound = cferrors.New(cferrors.CodeNotFound, "account not found")
    ErrAccountExists   = cferrors.New(cferrors.CodeAlreadyExists, "account with this email already exists")
)
```

### `internal/repository/credentials/`

**`api.go`:**
```go
type CredentialsRepository interface {
    Insert(ctx context.Context, row APIKeyRow) error
    GetByID(ctx context.Context, id string) (APIKeyRow, error)
    GetByHash(ctx context.Context, keyHash string) (APIKeyRow, error)
    ListByAccount(ctx context.Context, accountID string) ([]APIKeyRow, error)
    Revoke(ctx context.Context, id string, revokedAt time.Time) error
}

func New(session *scylladbclient.Session) CredentialsRepository
```

**`models.go`:**
```go
type APIKeyRow struct {
    ID        gocql.UUID
    AccountID gocql.UUID
    KeyHash   string
    KeyPrefix string
    CreatedAt time.Time
    RevokedAt *time.Time
}
```

**`repository.go`:** Implement `CFAccountsCredentialsRepository`.
- `Insert`: writes to `api_keys`, `api_keys_by_account`, and `api_keys_by_hash`
- `GetByID`: queries `api_keys`
- `GetByHash`: queries `api_keys_by_hash` — used in the hot authentication path; must be fast
- `ListByAccount`: queries `api_keys_by_account`
- `Revoke`: sets `revoked_at` in `api_keys` and `api_keys_by_hash`

**`errors.go`:**
```go
var (
    ErrCredentialNotFound = cferrors.New(cferrors.CodeNotFound, "API key not found")
    ErrCredentialRevoked  = cferrors.New(cferrors.CodeForbidden, "API key has been revoked")
)
```
