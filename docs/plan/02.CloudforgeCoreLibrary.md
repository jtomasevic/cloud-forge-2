### Package: `pkg/errors`

File: `libs/cloudforge-core/pkg/errors/errors.go`

Define the platform-wide typed error system. Rules from `docs/rest-services-rules.md`:
- Each layer has its own typed errors in `errors.go`
- Always preserve error cause/stack when wrapping
- Most can be static typed errors; use dynamic typed errors only when runtime context is required

Define the following base error type and sentinel errors that any CF service can wrap or extend:

```go
package errors

import "fmt"

// Code is a machine-readable error classification used across all CF services.
type Code string

const (
    CodeNotFound          Code = "NOT_FOUND"
    CodeAlreadyExists     Code = "ALREADY_EXISTS"
    CodeInvalidInput      Code = "INVALID_INPUT"
    CodeUnauthorized      Code = "UNAUTHORIZED"
    CodeForbidden         Code = "FORBIDDEN"
    CodeInternal          Code = "INTERNAL"
    CodeUnavailable       Code = "UNAVAILABLE"
    CodeConflict          Code = "CONFLICT"
    CodeProvisioningFailed Code = "PROVISIONING_FAILED"
)

// CFError is the base typed error for CloudForge platform errors.
// It always carries a Code, a human-readable message, and optionally
// the underlying cause. The cause is preserved for debugging but must
// not be surfaced to external callers.
type CFError struct {
    code    Code
    message string
    cause   error
}

func New(code Code, message string) *CFError {
    return &CFError{code: code, message: message}
}

func Wrap(code Code, message string, cause error) *CFError {
    return &CFError{code: code, message: message, cause: cause}
}

func (e *CFError) Code() Code    { return e.code }
func (e *CFError) Error() string { return fmt.Sprintf("[%s] %s", e.code, e.message) }
func (e *CFError) Unwrap() error { return e.cause }

// Is supports errors.Is comparisons by Code.
func (e *CFError) Is(target error) bool {
    t, ok := target.(*CFError)
    if !ok {
        return false
    }
    return e.code == t.code
}

// Sentinel errors for use with errors.Is across layer boundaries.
var (
    ErrNotFound      = New(CodeNotFound, "not found")
    ErrAlreadyExists = New(CodeAlreadyExists, "already exists")
    ErrInvalidInput  = New(CodeInvalidInput, "invalid input")
    ErrUnauthorized  = New(CodeUnauthorized, "unauthorized")
    ErrForbidden     = New(CodeForbidden, "forbidden")
    ErrInternal      = New(CodeInternal, "internal error")
    ErrUnavailable   = New(CodeUnavailable, "service unavailable")
    ErrConflict      = New(CodeConflict, "conflict")
)
```

### Package: `pkg/middleware`

File: `libs/cloudforge-core/pkg/middleware/middleware.go`

Implement the following standard HTTP middleware functions using only `net/http`. Each middleware wraps an `http.Handler` and returns an `http.Handler`.

**RequestID** — injects a unique request ID into the request context and sets it as the `X-Request-ID` response header. If the incoming request already has `X-Request-ID`, use the provided value.

**Logger** — logs method, path, status code, and duration for every request. Use `log/slog` (standard library in Go 1.21+). Log at INFO level.

**Recovery** — recovers from panics, logs the panic with a stack trace, and returns HTTP 500.

**Chain** — a helper that composes multiple middleware into a single `http.Handler`. Usage: `Chain(handler, RequestID, Logger, Recovery)`. Middleware is applied in the order given (outermost first).

Also provide a context key type and helper functions for request ID:

```go
// ContextKey is an unexported type for context keys in this package.
type ContextKey string

const RequestIDKey ContextKey = "request_id"

func RequestIDFromContext(ctx context.Context) string
func ContextWithRequestID(ctx context.Context, id string) context.Context
```

Use `crypto/rand` to generate request IDs as 16-byte hex strings.
