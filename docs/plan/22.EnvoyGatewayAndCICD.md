## Context

This final task has two parts:
1. **Envoy Gateway configuration** — the Kubernetes manifests that route public traffic through Envoy Gateway to CF-Router and expose tenant public endpoints
2. **GitHub Actions CI/CD** — all workflow files for linting, testing, codegen drift check, image building, and infrastructure validation

Reference: `docs/cf-private-network.md` sections 5.3 (Envoy Gateway position), 9.4 (security constraints), and 15 (CI/CD proposal).

## Part 1: Envoy Gateway Configuration

### `dev/k8s/gateway/gateway.yaml`

Define the `Gateway` resource that Envoy Gateway manages:

```yaml
apiVersion: gateway.networking.k8s.io/v1
kind: Gateway
metadata:
  name: cloudforge-gateway
  namespace: envoy-gateway-system
spec:
  gatewayClassName: cloudforge
  listeners:
    - name: http
      protocol: HTTP
      port: 80
    - name: https
      protocol: HTTPS
      port: 443
      tls:
        mode: Terminate
        certificateRefs:
          - kind: Secret
            name: cloudforge-tls
            namespace: envoy-gateway-system
```

### `dev/k8s/gateway/httproute-cf-router.yaml`

Route all CloudForge API traffic to CF-Router:

```yaml
apiVersion: gateway.networking.k8s.io/v1
kind: HTTPRoute
metadata:
  name: cf-router
  namespace: cloudforge-control-plane
spec:
  parentRefs:
    - name: cloudforge-gateway
      namespace: envoy-gateway-system
  hostnames:
    - "api.cloudforge.local"
  rules:
    - matches:
        - path:
            type: PathPrefix
            value: /v1
      backendRefs:
        - name: cf-router
          port: 8083
    - matches:
        - path:
            type: Exact
            value: /health
      backendRefs:
        - name: cf-router
          port: 8083
    - matches:
        - path:
            type: Exact
            value: /ready
      backendRefs:
        - name: cf-router
          port: 8083
```

### `dev/k8s/gateway/httproute-keycloak.yaml`

Route Keycloak console traffic:

```yaml
apiVersion: gateway.networking.k8s.io/v1
kind: HTTPRoute
metadata:
  name: keycloak
  namespace: cloudforge-control-plane
spec:
  parentRefs:
    - name: cloudforge-gateway
      namespace: envoy-gateway-system
  hostnames:
    - "auth.cloudforge.local"
  rules:
    - matches:
        - path:
            type: PathPrefix
            value: /
      backendRefs:
        - name: keycloak
          port: 8080
```

### `dev/k8s/gateway/dev-tls-cert.yaml`

Self-signed TLS certificate for local development (using cert-manager):

```yaml
apiVersion: cert-manager.io/v1
kind: Certificate
metadata:
  name: cloudforge-dev-tls
  namespace: envoy-gateway-system
spec:
  secretName: cloudforge-tls
  issuerRef:
    name: cloudforge-selfsigned
    kind: ClusterIssuer
  dnsNames:
    - "api.cloudforge.local"
    - "auth.cloudforge.local"
    - "*.gateway.cloudforge.local"
```

## Part 2: GitHub Actions CI/CD

All workflow files live in `.github/workflows/`.

### `.github/workflows/lint.yml`

```yaml
name: Lint

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  codegen-check:
    name: Codegen drift check
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-go@v5
        with:
          go-version: "1.23"
      - name: Install oapi-codegen
        run: go install github.com/oapi-codegen/oapi-codegen/v2/cmd/oapi-codegen@latest
      - name: Regenerate
        run: go generate ./...
      - name: Check for drift
        run: |
          git diff --exit-code -- '**/generated/*.gen.go' '**/clients/**/*.gen.go'
          echo "Generated files are up to date"

  lint:
    name: Lint (${{ matrix.module }})
    runs-on: ubuntu-latest
    strategy:
      fail-fast: false
      matrix:
        module:
          - services/cf-router
          - services/cf-accounts
          - services/cf-provisioner
          - libs/cloudforge-core
          - libs/scylladb
          - libs/openbao
          - libs/clients/cf-accounts
          - libs/clients/cf-provisioner
          - libs/clients/cf-router
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-go@v5
        with:
          go-version: "1.23"
      - name: go vet
        run: go vet ./...
        working-directory: ${{ matrix.module }}
      - uses: golangci/golangci-lint-action@v6
        with:
          working-directory: ${{ matrix.module }}
          version: latest
```

### `.github/workflows/test.yml`

```yaml
name: Test

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  unit-test:
    name: Unit tests (${{ matrix.module }})
    runs-on: ubuntu-latest
    strategy:
      fail-fast: false
      matrix:
        module:
          - services/cf-router
          - services/cf-accounts
          - services/cf-provisioner
          - libs/cloudforge-core
          - libs/scylladb
          - libs/openbao
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-go@v5
        with:
          go-version: "1.23"
      - name: Run unit tests
        run: go test -race -count=1 -timeout=60s ./...
        working-directory: ${{ matrix.module }}

  integration-test:
    name: Integration tests
    runs-on: ubuntu-latest
    # Only on PR to main and scheduled nightly
    if: github.event_name == 'pull_request' || github.event_name == 'schedule'
    services:
      scylladb:
        image: scylladb/scylla:5.4
        ports:
          - 9042:9042
        options: >-
          --health-cmd "cqlsh -e 'describe keyspaces'"
          --health-interval 10s
          --health-timeout 5s
          --health-retries 10
          --smp 1 --memory 512M --overprovisioned 1 --developer-mode 1
      openbao:
        image: hashicorp/vault:1.15
        ports:
          - 8200:8200
        env:
          VAULT_DEV_ROOT_TOKEN_ID: dev-root-token
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-go@v5
        with:
          go-version: "1.23"
      - name: Install k3d
        run: curl -s https://raw.githubusercontent.com/k3d-io/k3d/main/install.sh | bash
      - name: Create k3d cluster
        run: k3d cluster create ci-cluster --k3s-arg "--disable=traefik@server:0" --wait
      - name: Run schema migrations
        run: go run ./tools/migrations/... -hosts localhost:9042
      - name: Run CF-Accounts integration tests
        run: go test -tags=integration -race -timeout=10m ./...
        working-directory: services/cf-accounts
        env:
          SCYLLADB_HOSTS: localhost:9042
          OPENBAO_ADDR: http://localhost:8200
          OPENBAO_TOKEN: dev-root-token
      - name: Run CF-Provisioner integration tests
        run: go test -tags=integration -race -timeout=10m ./...
        working-directory: services/cf-provisioner
        env:
          SCYLLADB_HOSTS: localhost:9042
          OPENBAO_ADDR: http://localhost:8200
          OPENBAO_TOKEN: dev-root-token
          HOST_KUBECONFIG: ${{ env.KUBECONFIG }}
      - name: Cleanup k3d cluster
        if: always()
        run: k3d cluster delete ci-cluster
```

### `.github/workflows/build.yml`

```yaml
name: Build

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

env:
  REGISTRY: ghcr.io
  IMAGE_PREFIX: ghcr.io/jtomasevic/cloud-forge-2

jobs:
  build:
    name: Build image (${{ matrix.service }})
    runs-on: ubuntu-latest
    strategy:
      fail-fast: false
      matrix:
        service: [cf-accounts, cf-provisioner, cf-router]
    permissions:
      contents: read
      packages: write
    steps:
      - uses: actions/checkout@v4
      - uses: docker/setup-buildx-action@v3
      - uses: docker/login-action@v3
        if: github.ref == 'refs/heads/main'
        with:
          registry: ${{ env.REGISTRY }}
          username: ${{ github.actor }}
          password: ${{ secrets.GITHUB_TOKEN }}
      - name: Extract metadata
        id: meta
        uses: docker/metadata-action@v5
        with:
          images: ${{ env.IMAGE_PREFIX }}/${{ matrix.service }}
          tags: |
            type=sha,prefix=sha-
            type=ref,event=branch
            type=semver,pattern={{version}}
      - name: Build and push
        uses: docker/build-push-action@v5
        with:
          context: .
          file: services/${{ matrix.service }}/Dockerfile
          push: ${{ github.ref == 'refs/heads/main' }}
          tags: ${{ steps.meta.outputs.tags }}
          labels: ${{ steps.meta.outputs.labels }}
          cache-from: type=gha
          cache-to: type=gha,mode=max
```

### `.github/workflows/infra-validate.yml`

```yaml
name: Infrastructure Validation

on:
  push:
    paths:
      - 'dev/k8s/**'
      - 'api/**/*.yaml'
    branches: [main]
  pull_request:
    paths:
      - 'dev/k8s/**'
      - 'api/**/*.yaml'

jobs:
  validate-manifests:
    name: Validate Kubernetes manifests
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Install kubeconform
        run: |
          curl -L https://github.com/yannh/kubeconform/releases/latest/download/kubeconform-linux-amd64.tar.gz \
            | tar xz -C /usr/local/bin/
      - name: Validate manifests
        run: |
          find dev/k8s/manifests/ -name '*.yaml' | xargs kubeconform \
            -strict \
            -schema-location default \
            -schema-location 'https://raw.githubusercontent.com/datreeio/CRDs-catalog/main/{{.Group}}/{{.ResourceKind}}_{{.ResourceAPIVersion}}.json'

  validate-openapi:
    name: Validate OpenAPI specs
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Install Spectral
        run: npm install -g @stoplight/spectral-cli
      - name: Lint CF-Accounts spec
        run: spectral lint api/cf-accounts/v1/openapi.yaml
      - name: Lint CF-Provisioner spec
        run: spectral lint api/cf-provisioner/v1/openapi.yaml
      - name: Lint CF-Router spec
        run: spectral lint api/cf-router/v1/openapi.yaml
```

## Acceptance Criteria

- `kubectl apply -f dev/k8s/gateway/` deploys all gateway resources to k3d without errors
- `curl -H "Host: api.cloudforge.local" http://localhost:8080/health` returns 200 via Envoy Gateway
- All 5 GitHub Actions workflows are syntactically valid YAML
- `lint.yml` codegen-check job correctly detects drift when a `.gen.go` file is manually edited
- `build.yml` produces OCI images tagged with the git SHA
- `release.yml` tags images with the semver tag and `latest`
- `.golangci.yml` excludes linter errors in generated files
