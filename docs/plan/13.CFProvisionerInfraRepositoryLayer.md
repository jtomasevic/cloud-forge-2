# Task 13 — CF-Provisioner Infrastructure Repository Layer

## Context

CF-Provisioner's repository layer is split into two tasks because it has two distinct kinds of external dependencies:
1. **Infrastructure clients** (this task) — talking to live Kubernetes APIs: vCluster creation, Cilium policy management, Envoy Gateway HTTPRoute management, and OpenBao kubeconfig storage
2. **State repositories** (Task 14) — talking to ScyllaDB: CIDR allocations and provisioning jobs

Each infrastructure client follows the same repository layer conventions: `api.go` (interface), `client.go` (implementation), `models.go` (wire models), `errors.go` (typed errors).

Reference: `docs/cf-private-network.md` sections 5.2, 8.2, 9.2, 10.1, and 13.7.

## Dependencies

Tasks 1, 2, 4, and 12 must be complete.

## Prompt

You are implementing the infrastructure repository layer for **CF-Provisioner**. These packages talk to the host Kubernetes cluster, Cilium, Envoy Gateway, and OpenBao.

### Architecture rules (mandatory):
- Each package has `api.go`, `client.go`, `models.go`, `errors.go`
- The concrete struct is named `CF<Name>Client` — never exported, returned as interface from `New()`
- All errors are typed `CFError` values — raw Kubernetes or API errors never escape the interface
- All methods accept `context.Context`

### `internal/repository/vcluster/`

Manages vCluster instances via the host Kubernetes API. In the current architecture, a vCluster is provisioned by creating a `HelmRelease` (or equivalent) in the host cluster. For this implementation, use direct `helm` invocation via `os/exec` or the Kubernetes custom resource API if the vCluster operator is installed.

**`api.go`:**
```go
type VClusterClient interface {
    // Create provisions a new vCluster in the host cluster.
    Create(ctx context.Context, params CreateVClusterParams) (VClusterInfo, error)

    // Get returns the current status of a vCluster.
    Get(ctx context.Context, name string) (VClusterInfo, error)

    // Delete destroys a vCluster and all its resources.
    Delete(ctx context.Context, name string) error

    // GetKubeconfig retrieves the admin kubeconfig for the vCluster.
    GetKubeconfig(ctx context.Context, name string) ([]byte, error)
}

func New(hostKubeconfig []byte) (VClusterClient, error)
```

**`models.go`:**
```go
type CreateVClusterParams struct {
    Name      string // e.g. "tenant-abc-network-xyz"
    Namespace string // host namespace where the vCluster pods run
    PodCIDR   string
    SvcCIDR   string
    Region    string
}

type VClusterStatus string

const (
    VClusterStatusCreating VClusterStatus = "creating"
    VClusterStatusRunning  VClusterStatus = "running"
    VClusterStatusFailed   VClusterStatus = "failed"
    VClusterStatusDeleting VClusterStatus = "deleting"
)

type VClusterInfo struct {
    Name      string
    Namespace string
    Status    VClusterStatus
    PodCIDR   string
    SvcCIDR   string
}
```

**`client.go`:** Implement `CFVClusterClient`. Use the vCluster CLI approach via `os/exec` for the initial implementation, with a clear comment that this should be replaced by the vCluster operator API when available. The kubeconfig for the host cluster is loaded from the provided `hostKubeconfig` bytes using `k8s.io/client-go/tools/clientcmd`.

**`errors.go`:**
```go
var (
    ErrVClusterNotFound   = cferrors.New(cferrors.CodeNotFound, "vcluster not found")
    ErrVClusterExists     = cferrors.New(cferrors.CodeAlreadyExists, "vcluster already exists")
    ErrVClusterNotReady   = cferrors.New(cferrors.CodeUnavailable, "vcluster not ready")
    ErrKubeconfigNotReady = cferrors.New(cferrors.CodeUnavailable, "kubeconfig not available yet")
)
```

### `internal/repository/cilium/`

Manages `CiliumNetworkPolicy` objects in the host cluster to enforce default-deny between tenant vClusters.

**`api.go`:**
```go
type CiliumClient interface {
    // ApplyDefaultDenyPolicy creates the default-deny CiliumNetworkPolicy
    // for a vCluster namespace. Must be called immediately after vCluster creation.
    ApplyDefaultDenyPolicy(ctx context.Context, vclusterNamespace string, networkID string) error

    // ApplyIngressPolicy creates a policy allowing internet ingress to a specific
    // public subnet endpoint (used when provisioning an internet gateway).
    ApplyIngressPolicy(ctx context.Context, params IngressPolicyParams) error

    // RemovePolicy deletes a named CiliumNetworkPolicy.
    RemovePolicy(ctx context.Context, namespace, policyName string) error

    // GetPolicy returns the current state of a named policy.
    GetPolicy(ctx context.Context, namespace, policyName string) (PolicyInfo, error)
}

func New(hostKubeconfig []byte) (CiliumClient, error)
```

**`models.go`:**
```go
type IngressPolicyParams struct {
    VClusterNamespace string
    NetworkID         string
    PublicEndpointPort int
}

type PolicyInfo struct {
    Name      string
    Namespace string
    Exists    bool
}
```

**`client.go`:** Implement `CFCiliumClient`. Use `sigs.k8s.io/controller-runtime/pkg/client` with the Cilium CRD types. If Cilium CRD Go types are not available as a direct import, define minimal typed structs using `k8s.io/apimachinery/pkg/runtime` unstructured types. Document this clearly.

The default-deny policy YAML template to apply:
```yaml
apiVersion: cilium.io/v2
kind: CiliumNetworkPolicy
metadata:
  name: default-deny-egress-{networkID}
  namespace: {vclusterNamespace}
spec:
  endpointSelector: {}
  egressDeny:
    - toEntities:
        - "cluster"
```

**`errors.go`:**
```go
var (
    ErrPolicyNotFound    = cferrors.New(cferrors.CodeNotFound, "cilium policy not found")
    ErrPolicyApplyFailed = cferrors.New(cferrors.CodeInternal, "failed to apply cilium policy")
)
```

### `internal/repository/kubeconfig/`

Stores and retrieves tenant kubeconfigs in OpenBao. Wraps the `libs/openbao` convenience functions.

**`api.go`:**
```go
type KubeconfigRepository interface {
    Store(ctx context.Context, tenantID string, kubeconfigBytes []byte) error
    Load(ctx context.Context, tenantID string) ([]byte, error)
    Revoke(ctx context.Context, tenantID string) error
}

func New(secretsClient openbao.SecretsClient) KubeconfigRepository
```

**`client.go`:** Implement `CFKubeconfigRepository` by delegating directly to `openbao.StoreKubeconfig`, `LoadKubeconfig`, and `RevokeKubeconfig` from `libs/openbao/pkg/client`.

**`errors.go`:**
```go
var ErrKubeconfigNotFound = cferrors.New(cferrors.CodeNotFound, "kubeconfig not found — may have been revoked")
```
