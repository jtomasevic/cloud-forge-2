# Task 12 — CF-Provisioner Codegen

## Context

With the CF-Provisioner OpenAPI spec written, this task configures `oapi-codegen` and runs it to produce server stubs and a typed client library, following the same pattern established in Task 6 for CF-Accounts.

Reference: `docs/cf-private-network.md` sections 13.3, 13.4, and 13.5.

## Dependencies

Tasks 1 and 11 must be complete.

## Prompt

You are configuring and running code generation for **CF-Provisioner** using `oapi-codegen v2`. Follow the exact same pattern used for CF-Accounts in Task 6.

### Server stub configuration

File: `api/cf-provisioner/v1/oapi-server.cfg.yaml`

```yaml
package: generated
generate:
  strict-server: true
  models: true
  embedded-spec: true
output: ../../../services/cf-provisioner/internal/rest/generated/server.gen.go
```

### Client library configuration

File: `api/cf-provisioner/v1/oapi-client.cfg.yaml`

```yaml
package: cfprovisionerclient
generate:
  client: true
  models: true
output: ../../../libs/clients/cf-provisioner/v1/client.gen.go
```

### go:generate directive

File: `services/cf-provisioner/generate.go`

```go
package main

//go:generate oapi-codegen -config ../../api/cf-provisioner/v1/oapi-server.cfg.yaml ../../api/cf-provisioner/v1/openapi.yaml
//go:generate oapi-codegen -config ../../api/cf-provisioner/v1/oapi-client.cfg.yaml ../../api/cf-provisioner/v1/openapi.yaml
```

### Add runtime dependency

```bash
cd services/cf-provisioner && go get github.com/oapi-codegen/runtime
cd libs/clients/cf-provisioner && go get github.com/oapi-codegen/runtime
```

### Run codegen

```bash
oapi-codegen -config api/cf-provisioner/v1/oapi-server.cfg.yaml api/cf-provisioner/v1/openapi.yaml
oapi-codegen -config api/cf-provisioner/v1/oapi-client.cfg.yaml api/cf-provisioner/v1/openapi.yaml
```

### README for generated package

File: `services/cf-provisioner/internal/rest/generated/README.md`

```markdown
# Generated — DO NOT EDIT

Generated by oapi-codegen from `api/cf-provisioner/v1/openapi.yaml`.

To regenerate: `go generate ./...` from `services/cf-provisioner/`.
```

### Verify compilation

```bash
cd services/cf-provisioner && go build ./internal/rest/generated/...
cd libs/clients/cf-provisioner && go build ./...
```

---

## Acceptance Criteria

- `services/cf-provisioner/internal/rest/generated/server.gen.go` exists with `StrictServerInterface`
- `libs/clients/cf-provisioner/v1/client.gen.go` exists with a typed client
- Both compile without errors
- `go generate ./...` from `services/cf-provisioner/` regenerates both cleanly
