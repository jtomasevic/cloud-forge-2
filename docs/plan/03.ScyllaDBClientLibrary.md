# Task 3 — ScyllaDB Client Library

## Context

`libs/scylladb` provides a thin, reusable wrapper around the ScyllaDB (Cassandra-compatible) Go driver. It handles session creation, connection pooling configuration, and a lightweight migration runner used by the `tools/migrations` module. All CF services that persist state to ScyllaDB import this library.

Reference: `docs/cf-private-network.md` section 11.3 (ScyllaDB validation) and section 14.2 (module layout).

## Dependencies

Task 1 (repository skeleton) must be complete.

### Package: `pkg/client`

File: `libs/scylladb/pkg/client/client.go`

Implement a `Session` wrapper and a `Config` struct for session creation.

**Config:**
```go
type Config struct {
    Hosts    []string // e.g. ["localhost:9042"]
    Keyspace string
    Username string
    Password string
    // Timeout for individual queries. Defaults to 10s if zero.
    Timeout time.Duration
    // NumConns is the number of connections per host. Defaults to 2.
    NumConns int
}
```

**Session:**
- `New(ctx context.Context, cfg Config) (*Session, error)` — creates and returns a connected ScyllaDB session. Returns a wrapped `*CFError` with `CodeUnavailable` if the connection cannot be established. Uses `github.com/jtomasevic/cloud-forge-2/libs/cloudforge-core/pkg/errors` for error wrapping.
- `Session.Query(stmt string, values ...interface{}) *gocql.Query` — thin pass-through to the underlying gocql session
- `Session.Close()` — closes the underlying session

The session must use `gocql.LocalQuorum` as the default consistency level.

File: `libs/scylladb/pkg/client/errors.go`

Define a single typed error for connection failures:
```go
var ErrConnectionFailed = cferrors.New(cferrors.CodeUnavailable, "scylladb connection failed")
```

### Package: `pkg/migrate`

File: `libs/scylladb/pkg/migrate/migrate.go`

Implement a simple migration runner that applies `.cql` scripts in sorted filename order.

**MigrationConfig:**
```go
type MigrationConfig struct {
    Session    *client.Session
    ScriptsDir string // path to directory containing .cql migration files
}
```

**RunMigrations(ctx context.Context, cfg MigrationConfig) error**
- Reads all `*.cql` files from `ScriptsDir`, sorted lexicographically by filename
- Applies each script as a single CQL statement (split on `;` to handle multi-statement files)
- Creates a `schema_migrations` table in the keyspace if it does not exist:
  ```cql
  CREATE TABLE IF NOT EXISTS schema_migrations (
      filename TEXT PRIMARY KEY,
      applied_at TIMESTAMP
  );
  ```
- Skips files already recorded in `schema_migrations`
- Records each successfully applied file in `schema_migrations`
- Returns a wrapped error on any failure, preserving the cause
