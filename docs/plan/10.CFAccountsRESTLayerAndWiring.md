## Context

This task completes CF-Accounts by implementing the REST layer (handlers, server wiring, error mapping, model transforms) and the `main.go` entry point. After this task, CF-Accounts is a fully runnable HTTP service.

Reference: `docs/cf-private-network.md` section 13.7 (REST layer file conventions) and `docs/rest-services-rules.md` (REST layer rules).

## Prompt

You are implementing the REST layer and server wiring for **CF-Accounts**.

### Architecture rules (mandatory):
- `handler.go` implements the generated `StrictServerInterface` — no logic, only transforms + service calls
- `server.go` builds the `http.ServeMux` and wires the middleware chain
- `models.go` defines any REST request/response types not already covered by generated types
- `models_transform.go` maps between generated REST types and service-layer types
- `errors.go` maps service errors to HTTP status codes and error response bodies
- REST models never go below the REST layer
- Use only `net/http`, Go 1.22+ routing patterns, and `http.Handler` composition
- No third-party frameworks or routers

---

### `internal/rest/handler.go`

Implement `StrictServerInterface` (from `internal/rest/generated/server.gen.go`). Every method:
1. Calls the appropriate transform to convert the generated request type to a service params type
2. Calls the service method
3. On error: calls `mapServiceError(err)` to get the REST error response and status code
4. On success: calls the appropriate transform to convert the service model to the generated response type

Example pattern:
```go
func (h *Handler) CreateAccount(ctx context.Context, request generated.CreateAccountRequestObject) (generated.CreateAccountResponseObject, error) {
    params := request.Body.ToServiceCreateAccountParams()
    account, err := h.service.CreateAccount(ctx, params)
    if err != nil {
        return mapCreateAccountError(err), nil
    }
    return generated.CreateAccount201JSONResponse(ToCreateAccountResponseFromService(account)), nil
}
```

The `Handler` struct holds a reference to `AccountsService`. Its constructor:
```go
func NewHandler(svc service.AccountsService) *Handler
```

### `internal/rest/models_transform.go`

Implement transform methods following the naming convention from `docs/cf-private-network.md` section 13.8.

For each operation, define:
- A method on the generated request body type to produce a service params type: `(r *generated.CreateAccountRequest).ToServiceCreateAccountParams() service.CreateAccountParams`
- A free function to convert a service model to the generated response type: `ToAccountResponseFromService(a service.Account) generated.Account`

All transforms must be explicit — no field copying shortcuts, no `reflect`. Each field is assigned individually so that schema changes are caught at compile time.

### `internal/rest/errors.go`

Implement error mapping from service errors to HTTP responses:

```go
func mapServiceError(err error) (int, generated.Error) {
    var cfErr *cferrors.CFError
    if !errors.As(err, &cfErr) {
        return http.StatusInternalServerError, generated.Error{
            Code:    "INTERNAL",
            Message: "an unexpected error occurred",
        }
    }

    switch cfErr.Code() {
    case cferrors.CodeNotFound:
        return http.StatusNotFound, generated.Error{Code: "NOT_FOUND", Message: cfErr.Error()}
    case cferrors.CodeAlreadyExists:
        return http.StatusConflict, generated.Error{Code: "ALREADY_EXISTS", Message: cfErr.Error()}
    case cferrors.CodeInvalidInput:
        return http.StatusBadRequest, generated.Error{Code: "INVALID_INPUT", Message: cfErr.Error()}
    case cferrors.CodeUnauthorized:
        return http.StatusUnauthorized, generated.Error{Code: "UNAUTHORIZED", Message: cfErr.Error()}
    case cferrors.CodeForbidden:
        return http.StatusForbidden, generated.Error{Code: "FORBIDDEN", Message: cfErr.Error()}
    case cferrors.CodeConflict:
        return http.StatusConflict, generated.Error{Code: "CONFLICT", Message: cfErr.Error()}
    default:
        return http.StatusInternalServerError, generated.Error{Code: "INTERNAL", Message: "internal error"}
    }
}
```

Never expose internal error details (stack traces, raw DB errors) in the response body. Log the full error using `slog` with the request ID from context.

### `main.go`

File: `services/cf-accounts/main.go`

```go
package main

import (
    "context"
    "log/slog"
    "net/http"
    "os"
    "time"

    scyllaClient "github.com/jtomasevic/cloud-forge-2/libs/scylladb/pkg/client"
    "github.com/jtomasevic/cloud-forge-2/services/cf-accounts/internal/repository/accounts"
    "github.com/jtomasevic/cloud-forge-2/services/cf-accounts/internal/repository/credentials"
    "github.com/jtomasevic/cloud-forge-2/services/cf-accounts/internal/repository/networks"
    "github.com/jtomasevic/cloud-forge-2/services/cf-accounts/internal/repository/tenants"
    "github.com/jtomasevic/cloud-forge-2/services/cf-accounts/internal/rest"
    "github.com/jtomasevic/cloud-forge-2/services/cf-accounts/internal/service"
)

func main() {
    logger := slog.New(slog.NewJSONHandler(os.Stdout, nil))
    slog.SetDefault(logger)

    hosts := envOr("SCYLLADB_HOSTS", "localhost:9042")
    keyspace := envOr("SCYLLADB_KEYSPACE", "cloudforge")
    addr := envOr("HTTP_ADDR", ":8081")

    session, err := scyllaClient.New(context.Background(), scyllaClient.Config{
        Hosts:    splitHosts(hosts),
        Keyspace: keyspace,
    })
    if err != nil {
        slog.Error("failed to connect to ScyllaDB", "error", err)
        os.Exit(1)
    }
    defer session.Close()

    svc := service.New(service.Deps{
        Accounts:    accounts.New(session),
        Tenants:     tenants.New(session),
        Networks:    networks.New(session),
        Credentials: credentials.New(session),
    })

    handler := rest.NewHandler(svc)
    router := rest.NewRouter(handler)

    srv := &http.Server{
        Addr:         addr,
        Handler:      router,
        ReadTimeout:  15 * time.Second,
        WriteTimeout: 15 * time.Second,
        IdleTimeout:  60 * time.Second,
    }

    slog.Info("cf-accounts starting", "addr", addr)
    if err := srv.ListenAndServe(); err != nil && err != http.ErrServerClosed {
        slog.Error("server error", "error", err)
        os.Exit(1)
    }
}
```

Implement `envOr` and `splitHosts` as unexported helper functions in `main.go`.

### Dockerfile

File: `services/cf-accounts/Dockerfile`

```dockerfile
FROM golang:1.23-alpine AS builder
WORKDIR /build

# Copy go.work so all modules are available
COPY go.work go.work.sum ./
COPY libs/ libs/
COPY services/cf-accounts/ services/cf-accounts/

WORKDIR /build/services/cf-accounts
RUN go build -o /bin/cf-accounts ./...

FROM gcr.io/distroless/static:nonroot
COPY --from=builder /bin/cf-accounts /cf-accounts
ENTRYPOINT ["/cf-accounts"]
```

Note: the Dockerfile copies the full workspace context from the repository root because `go.work` spans multiple modules.
