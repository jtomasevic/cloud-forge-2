# Task 25 — CF-Provisioner Durable Subnet Persistence

## Context

CF App Service placement depends on durable private/public subnet records. Today `docs/cf-app-service.md` section 5.5 calls out a blocking limitation:

- Subnets are currently stored in process memory inside CF-Provisioner, not durably in ScyllaDB.

Resolve this before implementing app-service placement. A CF App Service must be able to validate that a requested subnet exists, belongs to the requested private network, and has the expected type (`private` or `public`) after process restarts.

Reference:

- `docs/cf-app-service.md`
- `docs/cf-private-network.md`
- `api/cf-provisioner/v1/openapi.yaml`
- `services/cf-provisioner/internal/service/models.go`
- `libs/cloudforge-core/pkg/network/network.go`

## Requirements

1. Add durable ScyllaDB storage for subnets.
2. Replace the in-process `subnetsByNetwork` map in CF-Provisioner with a repository-backed implementation.
3. Preserve existing CF-Provisioner subnet API behavior:
   - `POST /v1/networks/{networkId}/subnets`
   - `GET /v1/networks/{networkId}/subnets`
4. Keep subnet IDs stable UUIDs.
5. Enforce:
   - `networkId` is required
   - `type` is one of `private`, `public`
   - `cidr` is required and syntactically valid
   - `zone` is optional
6. Add uniqueness rules that prevent duplicate subnet CIDRs within the same network.
7. Ensure app-service tasks later can call a repository method like `GetByID(ctx, networkID, subnetID)`.

## Implementation Notes

Create a new repository package:

```text
services/cf-provisioner/internal/repository/subnets/
```

Expected files:

- `api.go`
- `commands.go`
- `errors.go`
- `models.go`
- `repository.go`
- `repository_test.go`
- `README.md`

The package should follow the repository style used by `cidr` and `jobs`.

Suggested ScyllaDB tables:

```sql
CREATE TABLE IF NOT EXISTS subnets (
  id uuid PRIMARY KEY,
  network_id uuid,
  type text,
  cidr text,
  zone text,
  created_at timestamp
);

CREATE TABLE IF NOT EXISTS subnets_by_network (
  network_id uuid,
  subnet_id uuid,
  type text,
  cidr text,
  zone text,
  created_at timestamp,
  PRIMARY KEY (network_id, subnet_id)
);
```

If duplicate CIDR detection cannot be enforced by schema alone, enforce it in the repository/service layer before insert.

## Acceptance Criteria

- Subnet records survive CF-Provisioner process restart.
- `ProvisionSubnet` writes to ScyllaDB.
- `ListSubnets` reads from ScyllaDB.
- Duplicate subnet CIDR in the same network is rejected.
- Unit tests cover create/list/get duplicate validation and not-found behavior.
- Existing subnet OpenAPI contract remains compatible unless a deliberate spec change is documented.
