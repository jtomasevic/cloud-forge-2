# Task 37 — CF App Service Production Hardening And CI/CD

## Context

After the local MVP works, CF App Service needs production constraints and CI coverage. Production mode must not rely on local Dockerfile builds or undocumented gateway behavior.

Reference:

- `docs/cf-app-service.md`
- `.github/workflows/`
- `Makefile`
- `dev/k8s/`

## Requirements

1. Require production app services to use registry image references.
2. Decide whether production accepts mutable tags or requires immutable digests.
3. Add resource guardrails:
   - max CPU
   - max memory
   - max app services per network
   - max public services per tenant
4. Add validation for public hostnames and future DNS ownership.
5. Define TLS behavior for public app services.
6. Add CI checks for:
   - OpenAPI validation
   - codegen drift
   - unit tests
   - app-service repository/service tests
   - example manifest validation
7. Update image build workflows if new service binaries or examples are added.
8. Update Makefile targets if new verification commands are needed.
9. Document production assumptions and non-goals.

## Acceptance Criteria

- CI validates app-service API and codegen.
- CI runs app-service unit tests.
- Production docs state image, DNS, TLS, and quota assumptions.
- Makefile help lists any new developer commands.
- Public Swagger requirement is documented in production guidance.
