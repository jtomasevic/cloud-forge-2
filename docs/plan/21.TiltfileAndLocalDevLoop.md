# Task 21 — Tiltfile and Local Development Loop

## Context

Tilt provides a live-reload development loop that rebuilds and redeploys CF services whenever source files change. After this task, a developer can run `tilt up` and have all three CF services running locally — either as Go binaries or in k3d — with changes reflected within seconds.

Reference: `docs/cf-private-network.md` section 12.4 (Tilt for the local dev loop).

## Dependencies

Tasks 10, 16, 18 (all three services must build), 19 (k3d cluster), and 20 (Docker Compose backing services) must be complete.

## Prompt

You are creating the Tiltfile and Makefile targets for the **CloudForge** local development loop.

---

### Development mode: two modes

Provide two dev modes, switchable via environment variable `CF_DEV_MODE`:
- `local` (default) — run CF services as Go binaries directly on the host (fastest, no Docker build)
- `k8s` — build Docker images and deploy into k3d (closer to production)

The `Tiltfile` must support both modes.

---

### `Tiltfile`

File: `Tiltfile` (at repository root)

```python
# CloudForge Tiltfile
# Modes: CF_DEV_MODE=local (default) | CF_DEV_MODE=k8s

dev_mode = os.getenv('CF_DEV_MODE', 'local')

# ── Backing services (Docker Compose) ────────────────────────────────────────
docker_compose('dev/docker-compose.yml')

dc_resource('scylladb',   labels=['backing-services'])
dc_resource('openbao',    labels=['backing-services'])
dc_resource('keycloak',   labels=['backing-services'])

# ── Schema migrations (run once after ScyllaDB is ready) ──────────────────────
local_resource(
    'db-migrate',
    cmd='go run ./tools/migrations/... -hosts localhost:9042',
    deps=['tools/migrations/scripts/'],
    resource_deps=['scylladb'],
    labels=['infra'],
)

# ── OpenBao init (run once after OpenBao is ready) ───────────────────────────
local_resource(
    'openbao-init',
    cmd='dev/scripts/init-openbao.sh',
    resource_deps=['openbao'],
    labels=['infra'],
)

if dev_mode == 'local':
    # ── Local binary mode ─────────────────────────────────────────────────────
    # Services run as Go binaries on the host. Changes to source files trigger
    # an automatic rebuild and restart.

    local_resource(
        'cf-accounts',
        serve_cmd='go run ./services/cf-accounts/...',
        deps=['services/cf-accounts/', 'libs/cloudforge-core/', 'libs/scylladb/'],
        env={
            'HTTP_ADDR': ':8081',
            'SCYLLADB_HOSTS': 'localhost:9042',
            'SCYLLADB_KEYSPACE': 'cloudforge',
        },
        resource_deps=['db-migrate'],
        labels=['cf-services'],
        readiness_probe=probe(
            http_get=http_get_action(port=8081, path='/v1/accounts'),
            period_secs=3,
        ),
    )

    local_resource(
        'cf-provisioner',
        serve_cmd='go run ./services/cf-provisioner/...',
        deps=['services/cf-provisioner/', 'libs/cloudforge-core/', 'libs/scylladb/', 'libs/openbao/'],
        env={
            'HTTP_ADDR': ':8082',
            'SCYLLADB_HOSTS': 'localhost:9042',
            'OPENBAO_ADDR': 'http://localhost:8200',
            'OPENBAO_TOKEN': 'dev-root-token',
            'CF_INTERNAL_SECRET': 'dev-internal-secret',
            'HOST_KUBECONFIG': os.getenv('HOME') + '/.kube/config',
        },
        resource_deps=['db-migrate', 'openbao-init'],
        labels=['cf-services'],
        readiness_probe=probe(
            http_get=http_get_action(port=8082, path='/health'),
            period_secs=3,
        ),
    )

    local_resource(
        'cf-router',
        serve_cmd='go run ./services/cf-router/...',
        deps=['services/cf-router/', 'libs/cloudforge-core/', 'libs/scylladb/', 'libs/clients/cf-accounts/'],
        env={
            'HTTP_ADDR': ':8083',
            'SCYLLADB_HOSTS': 'localhost:9042',
            'CF_ACCOUNTS_URL': 'http://localhost:8081',
            'CF_INTERNAL_SECRET': 'dev-internal-secret',
            'KEYCLOAK_JWKS_URL': 'http://localhost:8084/auth/realms/cloudforge/protocol/openid-connect/certs',
        },
        resource_deps=['cf-accounts'],
        labels=['cf-services'],
        readiness_probe=probe(
            http_get=http_get_action(port=8083, path='/health'),
            period_secs=3,
        ),
    )

else:
    # ── k8s mode ──────────────────────────────────────────────────────────────
    # Services are built as Docker images and deployed into k3d.

    for svc in ['cf-accounts', 'cf-provisioner', 'cf-router']:
        port = {'cf-accounts': 8081, 'cf-provisioner': 8082, 'cf-router': 8083}[svc]
        docker_build(
            'ghcr.io/jtomasevic/cloud-forge-2/' + svc,
            context='.',
            dockerfile='services/' + svc + '/Dockerfile',
            live_update=[
                sync('services/' + svc + '/', '/app/services/' + svc + '/'),
                sync('libs/', '/app/libs/'),
            ],
        )
        k8s_yaml('dev/k8s/manifests/' + svc + '.yaml')
        k8s_resource(svc, port_forwards=str(port) + ':' + str(port), labels=['cf-services'])
```

### Kubernetes manifests for k8s mode

Create minimal Kubernetes `Deployment` and `Service` manifests for each CF service. These are used only in `k8s` mode.

File: `dev/k8s/manifests/cf-accounts.yaml`

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: cf-accounts
  namespace: cloudforge-control-plane
spec:
  replicas: 1
  selector:
    matchLabels:
      app: cf-accounts
  template:
    metadata:
      labels:
        app: cf-accounts
    spec:
      containers:
        - name: cf-accounts
          image: ghcr.io/jtomasevic/cloud-forge-2/cf-accounts
          ports:
            - containerPort: 8081
          env:
            - name: HTTP_ADDR
              value: ":8081"
            - name: SCYLLADB_HOSTS
              value: "host.k3d.internal:9042"
            - name: SCYLLADB_KEYSPACE
              value: "cloudforge"
          readinessProbe:
            httpGet:
              path: /v1/accounts
              port: 8081
            initialDelaySeconds: 5
            periodSeconds: 5
---
apiVersion: v1
kind: Service
metadata:
  name: cf-accounts
  namespace: cloudforge-control-plane
spec:
  selector:
    app: cf-accounts
  ports:
    - port: 8081
      targetPort: 8081
```

Create equivalent manifests for `cf-provisioner` (port 8082) and `cf-router` (port 8083) following the same pattern.

**Note:** `host.k3d.internal` is the hostname that resolves to the Docker host from within k3d, allowing pods to reach the Docker Compose services (ScyllaDB, OpenBao, Keycloak) running on the host.

### Makefile targets

Add the following targets to the root `Makefile`:

```makefile
.PHONY: dev tilt-up tilt-down dev-tools

dev: dev-init k3d-up k3d-install-deps
	@echo "Dev environment ready. Run 'make tilt-up' to start services."

tilt-up:
	tilt up

tilt-down:
	tilt down

dev-tools:
	@echo "Installing dev tools..."
	go install github.com/oapi-codegen/oapi-codegen/v2/cmd/oapi-codegen@latest
	@echo "Install the following tools manually if not present:"
	@echo "  k3d:     https://k3d.io/#installation"
	@echo "  tilt:    https://docs.tilt.dev/install.html"
	@echo "  helm:    https://helm.sh/docs/intro/install/"
	@echo "  kubectl: https://kubernetes.io/docs/tasks/tools/"
```

### Smoke test script

File: `dev/scripts/smoke-test.sh`

A quick end-to-end smoke test that validates the local dev environment is working:

```bash
#!/usr/bin/env bash
set -euo pipefail

BASE_URL="${CF_ROUTER_URL:-http://localhost:8083}"

echo "=== CloudForge Dev Smoke Test ==="

echo "1. Health check..."
curl -sf "${BASE_URL}/health" | grep '"status":"ok"'
echo "   PASS"

echo "2. Get API key JWT..."
TOKEN=$(curl -sf -X POST \
    "http://localhost:8084/auth/realms/cloudforge/protocol/openid-connect/token" \
    -d "grant_type=password&client_id=cf-console&username=dev-user@cloudforge.io&password=devpassword" \
    | python3 -c "import sys,json; print(json.load(sys.stdin)['access_token'])")
echo "   PASS (token obtained)"

echo "3. Create account via CF-Router..."
ACCOUNT=$(curl -sf -X POST "${BASE_URL}/v1/accounts" \
    -H "Authorization: Bearer ${TOKEN}" \
    -H "Content-Type: application/json" \
    -d '{"email":"smoke-test@example.com"}')
ACCOUNT_ID=$(echo "${ACCOUNT}" | python3 -c "import sys,json; print(json.load(sys.stdin)['id'])")
echo "   PASS (account ID: ${ACCOUNT_ID})"

echo "4. Get account..."
curl -sf "${BASE_URL}/v1/accounts/${ACCOUNT_ID}" \
    -H "Authorization: Bearer ${TOKEN}" | grep '"status":"active"'
echo "   PASS"

echo "=== Smoke test passed ==="
```

## Acceptance Criteria

- `tilt up` starts all resources without errors in `local` mode
- Changes to `services/cf-accounts/**/*.go` trigger a rebuild and restart of `cf-accounts` within 3 seconds
- `make dev-tools` installs `oapi-codegen`
- `dev/scripts/smoke-test.sh` passes end-to-end (requires all services running)
- In `CF_DEV_MODE=k8s` mode, all three services deploy to k3d and are accessible via port-forwards
