# Task 15 — CF-Provisioner Service Layer

## Context

The CF-Provisioner service layer orchestrates all infrastructure operations: it coordinates CIDR allocation, vCluster creation, Cilium policy application, kubeconfig storage, and gateway provisioning. Most operations are asynchronous — the service immediately creates a job record and returns it, then executes the actual work in a goroutine.

Reference: `docs/cf-private-network.md` sections 5.2 (CF-Provisioner responsibility), 8.2 (provisioning flow diagram), 9.2 (gateway flow), and 10.1 (control-plane communication model).

## Dependencies

Tasks 2, 13, and 14 must be complete.

type ProvisionerService interface {
    // ProvisionNetwork starts async provisioning of a tenant private network.
    // Returns a Job that the caller can poll via GetJob.
    ProvisionNetwork(ctx context.Context, params ProvisionNetworkParams) (Job, error)

    // GetNetworkStatus returns the current status of a provisioned network.
    GetNetworkStatus(ctx context.Context, networkID string) (NetworkStatus, error)

    // DeprovisionNetwork starts async deprovisioning.
    DeprovisionNetwork(ctx context.Context, networkID string) (Job, error)

    // ProvisionGateway provisions an internet gateway for a network.
    ProvisionGateway(ctx context.Context, params ProvisionGatewayParams) (Job, error)

    // GetGatewayStatus returns the current status of a gateway.
    GetGatewayStatus(ctx context.Context, networkID string) (GatewayStatus, error)

    // RemoveGateway removes the internet gateway.
    RemoveGateway(ctx context.Context, networkID string) (Job, error)

    // GetJob returns the current status of a provisioning job.
    GetJob(ctx context.Context, jobID string) (Job, error)

    // ListNetworkJobs returns all jobs for a network.
    ListNetworkJobs(ctx context.Context, networkID string) ([]Job, error)

    // ProvisionSubnet creates a subnet in a network.
    ProvisionSubnet(ctx context.Context, params ProvisionSubnetParams) (Subnet, error)

    // ListSubnets returns all subnets for a network.
    ListSubnets(ctx context.Context, networkID string) ([]Subnet, error)
}

### `internal/service/service.go`

Implement `CFProvisionerService`.

**ProvisionNetwork — async orchestration:**

```
1. Allocate CIDR (sync, fail fast if exhausted)
2. Create a Job record with type "provision_network" and status "pending"
3. Return the Job immediately (202 Accepted pattern)
4. In a goroutine:
   a. Update job status to "running"
   b. Determine vCluster name: "cf-{networkID[0:8]}"
   c. Create vCluster via VClusterClient.Create
   d. Wait for vCluster to reach "running" status (poll with exponential backoff, timeout 5 minutes)
   e. Apply default-deny Cilium policy via CiliumClient.ApplyDefaultDenyPolicy
   f. Retrieve kubeconfig via VClusterClient.GetKubeconfig
   g. Store kubeconfig via KubeconfigRepository.Store
   h. Update job status to "succeeded"
   i. On any error: update job status to "failed" with error message
```

**DeprovisionNetwork — async teardown:**
```
1. Look up the network's CIDR allocation to confirm it exists
2. Create a Job record with type "deprovision_network"
3. Return the Job immediately
4. In a goroutine:
   a. Revoke kubeconfig via KubeconfigRepository.Revoke
   b. Remove Cilium default-deny policy via CiliumClient.RemovePolicy
   c. Delete vCluster via VClusterClient.Delete
   d. Release CIDR allocation via CIDRRepository.Release
   e. Update job status to "succeeded"
```

**ProvisionGateway — async:**
```
1. Validate the network is in "active" status (look up via GetNetworkStatus)
2. Create a Job with type "provision_gateway"
3. Return the Job
4. In a goroutine:
   a. Create HTTPRoute via GatewayClient.CreateHTTPRoute
   b. Apply Cilium ingress policy via CiliumClient.ApplyIngressPolicy
   c. Update job status to "succeeded"
```

**Goroutine context:** Each background goroutine should use a new `context.Background()` (not the request context, which may be cancelled). Log errors using `log/slog`.

### Tests

Write unit tests with mock repositories and clients:
- `ProvisionNetwork` returns a job with status `pending` and triggers async work
- `DeprovisionNetwork` calls `KubeconfigRepository.Revoke` before `VClusterClient.Delete`
- `ProvisionNetwork` returns `ErrCIDRExhausted` (wrapped from repo) when CIDR allocation fails
- The async goroutine updates the job to `failed` when `VClusterClient.Create` returns an error

For async tests, use a small sleep or `sync.WaitGroup` to wait for the goroutine to complete.
