### `internal/rest/handler.go`

Implement `StrictServerInterface`. Every handler:
1. Transforms the generated request type to a service params type
2. Calls the service method
3. Maps errors via `mapServiceError`
4. Transforms the service response to the generated response type

Handlers for async operations return `202 Accepted` with the `Job` model:
```go
func (h *Handler) ProvisionNetwork(ctx context.Context, request generated.ProvisionNetworkRequestObject) (generated.ProvisionNetworkResponseObject, error) {
    params := request.Body.ToServiceProvisionNetworkParams()
    job, err := h.service.ProvisionNetwork(ctx, params)
    if err != nil {
        return mapProvisionNetworkError(err), nil
    }
    return generated.ProvisionNetwork202JSONResponse(ToJobResponseFromService(job)), nil
}
```

### `internal/rest/server.go`

Same pattern as CF-Accounts. Build `http.ServeMux` with Go 1.22+ routing and the middleware chain from `libs/cloudforge-core`.

**Internal secret validation middleware:**

CF-Provisioner uses `X-CF-Internal-Secret` for auth. Implement a middleware that validates this header against an expected value loaded from the environment variable `CF_INTERNAL_SECRET`. Reject with `401` if missing or incorrect.

```go
func InternalSecretAuth(secret string) func(http.Handler) http.Handler {
    return func(next http.Handler) http.Handler {
        return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
            if r.Header.Get("X-CF-Internal-Secret") != secret {
                w.WriteHeader(http.StatusUnauthorized)
                return
            }
            next.ServeHTTP(w, r)
        })
    }
}
```

Apply this middleware in `NewRouter` after the standard middleware chain.

### `main.go`

File: `services/cf-provisioner/main.go`

```go
package main

import (
    "context"
    "log/slog"
    "net/http"
    "os"
    "time"

    openbaoClient "github.com/jtomasevic/cloud-forge-2/libs/openbao/pkg/client"
    scyllaClient   "github.com/jtomasevic/cloud-forge-2/libs/scylladb/pkg/client"
    "github.com/jtomasevic/cloud-forge-2/services/cf-provisioner/internal/repository/cidr"
    "github.com/jtomasevic/cloud-forge-2/services/cf-provisioner/internal/repository/cilium"
    "github.com/jtomasevic/cloud-forge-2/services/cf-provisioner/internal/repository/gateway"
    "github.com/jtomasevic/cloud-forge-2/services/cf-provisioner/internal/repository/jobs"
    "github.com/jtomasevic/cloud-forge-2/services/cf-provisioner/internal/repository/kubeconfig"
    "github.com/jtomasevic/cloud-forge-2/services/cf-provisioner/internal/repository/vcluster"
    "github.com/jtomasevic/cloud-forge-2/services/cf-provisioner/internal/rest"
    "github.com/jtomasevic/cloud-forge-2/services/cf-provisioner/internal/service"
)

func main() {
    logger := slog.New(slog.NewJSONHandler(os.Stdout, nil))
    slog.SetDefault(logger)

    addr           := envOr("HTTP_ADDR", ":8082")
    scyllaHosts    := envOr("SCYLLADB_HOSTS", "localhost:9042")
    openbaoAddr    := envOr("OPENBAO_ADDR", "http://localhost:8200")
    openbaoToken   := envOr("OPENBAO_TOKEN", "dev-root-token")
    internalSecret := envOr("CF_INTERNAL_SECRET", "dev-internal-secret")
    kubeConfigPath := envOr("HOST_KUBECONFIG", "")

    session, err := scyllaClient.New(context.Background(), scyllaClient.Config{
        Hosts:    splitHosts(scyllaHosts),
        Keyspace: "cloudforge",
    })
    if err != nil {
        slog.Error("failed to connect to ScyllaDB", "error", err)
        os.Exit(1)
    }
    defer session.Close()

    secretsClient, err := openbaoClient.New(openbaoClient.Config{
        Address: openbaoAddr,
        Token:   openbaoToken,
    })
    if err != nil {
        slog.Error("failed to init OpenBao client", "error", err)
        os.Exit(1)
    }

    hostKubeconfig := loadHostKubeconfig(kubeConfigPath)

    vclusterClient, err := vcluster.New(hostKubeconfig)
    if err != nil {
        slog.Error("failed to init vcluster client", "error", err)
        os.Exit(1)
    }

    ciliumClient, err := cilium.New(hostKubeconfig)
    if err != nil {
        slog.Error("failed to init cilium client", "error", err)
        os.Exit(1)
    }

    gatewayClient, err := gateway.New(hostKubeconfig)
    if err != nil {
        slog.Error("failed to init gateway client", "error", err)
        os.Exit(1)
    }

    svc := service.New(service.Deps{
        VCluster:   vclusterClient,
        Cilium:     ciliumClient,
        Gateway:    gatewayClient,
        Kubeconfig: kubeconfig.New(secretsClient),
        CIDR:       cidr.New(session),
        Jobs:       jobs.New(session),
    })

    handler := rest.NewHandler(svc)
    router := rest.NewRouter(handler, internalSecret)

    srv := &http.Server{
        Addr:         addr,
        Handler:      router,
        ReadTimeout:  30 * time.Second,
        WriteTimeout: 30 * time.Second,
        IdleTimeout:  60 * time.Second,
    }

    slog.Info("cf-provisioner starting", "addr", addr)
    if err := srv.ListenAndServe(); err != nil && err != http.ErrServerClosed {
        slog.Error("server error", "error", err)
        os.Exit(1)
    }
}
```

Implement `envOr`, `splitHosts`, and `loadHostKubeconfig` as unexported helpers. `loadHostKubeconfig` reads the file at the given path and returns the bytes; if path is empty, it tries `~/.kube/config`.

### Dockerfile

File: `services/cf-provisioner/Dockerfile`

Same multi-stage pattern as CF-Accounts. Copy from the workspace root so `go.work` is available.

```dockerfile
FROM golang:1.26-alpine AS builder
WORKDIR /build
COPY go.work go.work.sum ./
COPY libs/ libs/
COPY services/cf-provisioner/ services/cf-provisioner/
WORKDIR /build/services/cf-provisioner
RUN go build -o /bin/cf-provisioner ./...

FROM gcr.io/distroless/static:nonroot
COPY --from=builder /bin/cf-provisioner /cf-provisioner
ENTRYPOINT ["/cf-provisioner"]
```
